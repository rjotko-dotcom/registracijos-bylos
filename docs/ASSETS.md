# Asset replacement guide

## Sprite frames

All Frėja animation frames live in `src/assets/freja/<state>/`. The central
mapping is `src/cat/sprites.ts` — add or swap files there and nothing else
needs to change.

The frames are **generated**, not committed by hand: `npm run assets` reads
the supplied photos listed in `scripts/generate-assets.mjs`, cuts the black
vignette backdrop off each one (`scripts/cutout.mjs`), and pads every result
onto one shared canvas so the bed never shifts between frames. Point
`SOURCES` at new photos and re-run to refresh the art.

### How the background removal works

Frėja cannot be separated from the backdrop by brightness or hue alone —
where her dark back meets it she is actually *darker* than the backdrop
(rgb 11,9,8 vs 28,22,16), so a threshold or flood fill eats the cat. Two
signals together do work:

* **brightness** — the cream bed reads 215+, well clear of the backdrop
  glow that tops out near 160
* **local texture** — her fur has detail (std-dev ~15-19) while the
  backdrop is a smooth gradient (~1-5), which finds the silhouette of her
  back where brightness cannot

The convex hull of those pixels is the subject outline; everything outside
is cleared and a thin band just inside is faded so no straight hull edge
shows against the pale room. Tuning constants sit at the top of
`scripts/cutout.mjs`.

## The room

`src/assets/scene/room.png` is real pixel art, drawn in code by
`scripts/room.mjs` at 120x138 and scaled up with nearest-neighbour so every
pixel stays a hard square. Edit the drawing calls there — wall, window,
shelf, plant, rug — and re-run `npm run assets`. Time of day is layered on
at runtime as a CSS tint, so only one room image ships.

Currently supplied frames (from the user's pixel-art set):

| File | Source |
| --- | --- |
| `idle/freja-idle-01.png` | alert Frėja in her donut bed |
| `pressed/freja-pressed-closed.png` | eyes closed, content |
| `purr/freja-purr-01.png` | eyes closed (same art as pressed for now) |
| `sleep/freja-sleep-01.png` | sleeping with Zz |
| `meow/freja-meow-01.png` | mouth slightly open |
| `meow/freja-meow-02.png` | mouth wide open, happy |
| `yawn/freja-yawn-01.png` | big yawn |

States without dedicated art (blink, sneeze, stretch, groom, fly-watch,
fly-pounce, play-ball, cuddle-paw, zoomies, eating) currently **reuse the
closest supplied frame** plus subtle CSS transforms. To add real frames:

1. Drop `freja-<state>-01.png`, `-02.png`… into the matching folder
   (create `blink/`, `stretch/`, `groom/`… as needed).
2. Import them in `src/cat/sprites.ts` and list them in the `frames` array
   for that state with a suitable `frameMs`.

Keep all frames the same aspect ratio and framing (same bed position) so
animation doesn't jump. Frames are rendered with `image-rendering: pixelated`
and are downscaled to ~720 px width by `npm run assets` (files > 400 KB).

## Audio

Files live in `src/assets/audio/`. The current WAVs are **synthesized
placeholders** generated by `scripts/generate-assets.mjs`. To use real
recordings of Frėja, simply replace the files (same names):

- `purr-loop.wav` — seamless purr loop (2–6 s, quiet, loopable)
- `meow-1.wav`, `meow-2.wav` — meows (a random one is picked)
- `chirp.wav` — short trill
- `soft-pop.wav` — UI confirmation blip

MP3/OGG also work: put the file in `src/assets/audio/` and update the
imports in `src/audio/AudioManager.ts` (`FILES` map).

## Icons

PWA icons are generated from the idle frame by `npm run assets` into
`public/pwa/`. Rerun after replacing the idle art.
